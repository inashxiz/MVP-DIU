# Biblioteca USM — MVP


### Requisitos

- Node >= 16.13.1
- npm >= 8.1.2

### Quick start

Instalar dependencias

```
npm install
```

Inicializar página

```
npm run dev
```

Abrir http://localhost:5050

### Paquetes incluídos

- [Webpack](https://webpack.js.org/)
- [React Router](https://reactrouter.com/en/main)
